## 1. 架构设计

纯前端单页应用，无后端服务。

```mermaid
graph TD
    "浏览器" --> "React应用层"
    "React应用层" --> "Zustand状态管理"
    "React应用层" --> "编辑区组件"
    "React应用层" --> "预览区组件"
    "预览区组件" --> "html2canvas导出"
```

## 2. 技术说明

- 前端：React@18 + TypeScript + TailwindCSS@3 + Vite
- 初始化工具：vite-init
- 状态管理：Zustand
- 图片导出：html2canvas
- 后端：无
- 数据库：无

## 3. 路由定义

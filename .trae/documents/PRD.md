## 1. 产品概述

古籍竖排文字卡片生成器是一款为古籍数字化团队设计的在线工具，用于快速生成社交媒体可分享的古籍摘句竖排文字卡片。

- 主要目的：将古籍文字以传统线装书样式（竖排、从右到左）呈现，配以装饰元素，生成精美图片
- 目标用户：古籍数字化团队、传统文化爱好者、教育工作者
- 产品价值：降低古籍内容的社交媒体传播门槛，提升传统文化的视觉呈现质量

## 2. 核心功能

### 2.1 功能模块

1. **主页面（单页应用）**：
   - 左侧编辑区：文字输入、字体选择、字号和行间距调节、装饰选项开关
   - 右侧实时预览区：竖排文字渲染、装饰元素展示
   - 导出功能：一键导出为图片

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页 | 文字编辑器 | 多行文本输入，实时同步预览 |
| 主页 | 字体选择器 | 提供至少3种衬线字体/楷体类字体切换 |
| 主页 | 字号调节 | 滑块调节字号范围（16px-48px） |
| 主页 | 行间距调节 | 滑块调节行间距范围（0.8-2.5） |
| 主页 | 装饰选项 | 红色句读圈点、版框边框开关 |
| 主页 | 竖排预览 | 从上到下、从右到左实时渲染文字，带装饰效果 |
| 主页 | 图片导出 | 将预览区域导出为PNG图片 |

## 3. 核心流程

用户在编辑区输入古籍文字 → 选择字体、调整字号和行间距 → 按需开启装饰元素 → 实时查看右侧预览效果 → 满意后点击导出按钮 → 浏览器自动下载PNG图片

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：仿古宣纸米黄色（#F5F0E6）为主背景，墨黑色（#1A1A1A）为文字色
- 点缀色：朱砂红（#C23A2B）用于句读圈点和装饰边框
- 整体风格：典雅、古朴、书卷气，模拟传统线装书的质感
- 字体：预览区使用楷体/宋体类字体，编辑区使用现代无衬线字体保证可读性
- 布局：左右分栏布局，桌面端左右各占约50%，移动端上下堆叠

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 主页 | 编辑区 | 卡片式容器，米黄色背景，深灰边框，表单控件统一圆角8px |
| 主页 | 预览区 | 仿宣纸纹理背景，版框用双线边框，文字竖排从右向左，红色圈点装饰 |
| 主页 | 顶部标题 | 衬线字体大标题，配细朱砂红色分隔线 |

### 4.3 响应式

- 桌面端（≥1024px）：左右双栏布局，编辑区40%，预览区60%
- 平板端（768px-1023px）：左右双栏，比例各50%
- 移动端（<768px）：上下堆叠，预览区在上，编辑区在下
- 所有交互元素在移动端放大至适合触摸的尺寸
